# Get started

1. Open the Windows **Start menu**, search for **Audio Transcription Service**, and launch it.
2. Click **Start** to begin transcription.
3. Open **Claude Desktop** and sign in if needed.
4. After some audio has been transcribed, ask about a conversation using a time or topic:
   - “Summarize the conversation from today around 10 AM.”
   - “Find the conversation where we discussed holiday plans.”
   - “What did we decide about the project deadline?”
5. Try different questions and see what you can find 🙂
6. Click **Stop** in Audio Transcription Service whenever you want transcription to stop.

## You choose when it runs

**The service can remain running throughout the day. It does not need a live call.** While running, it transcribes both your **system audio and microphone**, including audio outside calls. You decide when to click Start and Stop. Opening Claude is not what starts or stops transcription.

Claude can search saved transcripts by time or topic. It cannot retrieve conversations that were never transcribed. A fresh installation includes the default `small` Whisper model, so no initial model download is needed.

## If Claude says it has no memory

Try asking explicitly:

> Use CoreMcp to search my recorded audio transcripts for the conversation about holiday plans.

These recordings are separate from Claude’s built-in memory and previous Claude chats. Disabled account memory does not mean recorded transcripts are unavailable.

If CoreMcp is unavailable, fully quit Claude, including its tray icon, then reopen Claude Desktop. If a tool reports an error, keep the exact message for troubleshooting.
