This installer installs Audio Transcription Service (AMD build), CoreMcp, and the latest Claude Desktop for the current Windows user.

Windows 11 x64, internet access, and an AMD GPU/driver compatible with the bundled service are required. Quit Claude before proceeding. Existing Claude settings and other MCP servers are preserved; a backup is created before changing an existing configuration.

Run setup normally under an administrator-enabled Windows account and approve the administrator prompt for Claude. Do not enter credentials for a different account: setup stops to avoid registering Claude under the wrong user. Optional Windows features for Cowork are not enabled.

If you have customized the service database location, select the matching path on the next page. Start Audio Transcription Service after installation to create the database and record transcripts.

The service preserves existing configuration. If replacing a NVIDIA installation, update its GPU runtime configuration for AMD before starting the service.

Uninstalling the suite removes its MCP executable and setup helpers. Audio Transcription Service and Claude remain separately uninstallable through Windows Settings. Transcript data and Claude configuration/backups are retained.

The bundled service includes the default small Whisper model, so a fresh installation does not need to download it before transcription. The service installer manages model provisioning and preserves existing configuration and model directories.

This AMD build targets supported gfx1031 hardware and was validated upstream on Radeon RX 6800M. Other AMD architectures are not assumed compatible.
