This installer installs Audio Transcription Service (AMD build), CoreMcp, and the latest Claude Desktop for the current Windows user.

Internet access and an AMD GPU/driver compatible with the bundled service are required. Quit Claude before proceeding. Existing Claude settings and other MCP servers are preserved; a backup is created before changing an existing configuration.

Run setup as your normal Windows user. The Claude MSIX installation supports chat and local MCP; this installer does not enable optional Windows features for Cowork.

If you have customized the service database location, select the matching path on the next page. Start Audio Transcription Service after installation to create the database and record transcripts.

The service preserves existing configuration. If replacing a NVIDIA installation, update its GPU runtime configuration for AMD before starting the service.

Uninstalling the suite removes its MCP executable and setup helpers. Audio Transcription Service and Claude remain separately uninstallable through Windows Settings. Transcript data and Claude configuration/backups are retained.
